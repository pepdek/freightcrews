| Found | Fix |
| --- | --- |
| Hours widget had an empty band under the last row when the Replay button was absent | Footer row collapses without the button |
| Hours counter was too quiet to read as the point of the card | Larger tabular numerals |
| Widget task names wrapped early on phones | Task takes the full row; hours and status sit below |
| "Replaces" tags wrapped into two-line pills | Arrow moved beside the title, tighter tags, two-up grid starts at 820px |
| Monogram tile read as an empty photo frame | Smaller square tile with the accent rule |
| Four to five type sizes in the pricing sections | Offer names set as mono labels; link and note sizes aligned |
| Timeline floated off the page's left edge | Aligned to the container |
| Tablet menu sheet did not line up with the header | Matching side padding |
| "30 min /day" gap on metric cards | Slash units sit tight |
| Hero and closing paragraphs broke unevenly | Balanced wrapping |
